# Word & Char Counter 🔡

Live word, character and line count for a textarea. No dependencies.

## What it is
A live text-statistics widget. As you type it updates the character, word and line counts in real time. Handy for bio fields, tweet-style limits or writing boxes.

## Usage
```js
count(text) -> {chars, words, lines}
```
